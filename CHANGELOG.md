Version 0.1.0 (November 7th 2026)
-----------------------------
 * Initial release of `@1pizzateam/facer` (`FaceR.js`):
    * Anatomical base head topology (`getCanonicalBaseHead`, `computeSmoothNormals`): 2,312 vertices and 4,262 triangles in 6 submeshes (`FACE_REGIONS`, `FACE_REGION_IDS`: skin, eyes, teeth, inner mouth) including a procedural hair cap, plus 7 base head archetypes (`BASE_HEAD_IDS`) distributed as separate `.facerhead.json` assets that each app keeps (none live in this repository) and loads with `loadBaseHead` / `registerBaseHead` (the library bundles no meshes) and hair styles as separate `.facerhair.json` assets (`loadHairStyle`, `registerHairStyle`; only `'bald'` is built in) that the game owns.
    * Automatic FACS rig transfer (`applyMacroProportions`, `computeFacsMuscles`, `FACS_MUSCLE_NAMES`) projecting 31 sparse muscle morph targets onto any head, including Wavefront `.obj` imports (`parseObjToTopology`, `parseObjToCartridge`).
    * Cartridge schema, defaults and `.facer` JSON serialization (`createDefaultProportions`, `createDefaultEmotions`, `createDefaultPersonality`, `createDefaultAppearance`, `createDefaultCartridge`, `rebuildCartridgeRig`, `serializeCartridge`, `hydrateCartridge`). Hydration validates saved muscle deltas and falls back to recomputing the rig.
    * `FaceR` runtime controller with layered emotions, autonomous gaze, blinking, impulses (`pain`, `shoot`, `surprise`, `glance`, `evilGrin`), held shooting snarl (`setShooting`), health-driven 5-tier damage state, and runtime base head / haircut switching. Built on `Perlin1D`, `ExpressionCompositor`, `GazeController`, `BlinkController` and `ImpulseController`.
    * Zero-allocation sparse CPU morph deformer (`evaluateFaceDeformation`, `rotateVec3ByQuat`), damage texture atlas hook (`registerAtlasPainter`, `generateFaceAtlasPixels`: the game supplies the painter, flat skin colour by default). Emotions, default colours, personality, damage tiers (swelling zones, wounded grimace), impulse recipes and the mesh material come from a game-supplied face profile (`loadFaceProfile`, `registerFaceProfile`, `deserializeFaceProfile`) and `@1pizzateam/roostr` WebGL mesh integration (`createRoostrFaceMesh`, `syncRoostrMeshBuffers`).
    * Re-exports the `@1pizzateam/spock` math types used by the API (`Vec2`, `Vec3`, `Quat`, …). Requires `@1pizzateam/spock` 4.6.0 (`Mat4x3.transformPoints`, `Mat4x3.transformDirections`, `Vec3.getEllipsoidDistance`).
    * Deformer performance: per-rig lookup tables (pivot vertex lists, neck/jaw weights, trauma falloffs) are cached and the pivot passes run through Spock bulk transforms, about 2–3× faster than the first prototype (`invalidateDeformCache` is exported for manual rest-pose edits).
    * Hardening: non-finite `dt`, weights, intensities and gaze angles are ignored instead of corrupting the mesh; `dt` is clamped to 0.25 s; the impulse queue is capped; malformed `.obj` faces are discarded and an `.obj` with no usable geometry throws.
