# Head asset

`african_sculpt.facerhead.json` is derived from the ZBrush sculpt **`african_head.obj` by Vidar Rapp**, as distributed with the
[tinyrenderer](https://github.com/ssloy/tinyrenderer) tutorial. Symmetrized across X=0 and re-topologized with lip-separation seams.
The original asset set lives in DoomR (`src/heads`); FaceR bundles no heads.
